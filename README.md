# معامل RT للتحاليل التشخيصية - نظام التسعير والعروض الذكية
## RT Diagnostic Laboratories - Smart Pricing, Daily Offers & WhatsApp Billing System
### معامل د. رامي مختار - استشاري التحاليل الطبية والباثولوجيا الإكلينيكية

---

## 🌟 نظرة عامة (Overview)
تطبيق متكامل وتفاعلي لتسعير الفحوصات والتحاليل الطبية تلقائياً وإدارة باقات الفحص الشامل والعروض اليومية (Flash Daily Offers)، مع إمكانية التثبيت كتطبيق (PWA) على الهواتف الذكية وأجهزة الكمبيوتر المحمولة، والعمل **دون اتصال بالإنترنت 100% (Offline-First)** مع حفظ محلي كامل لقاعدة البيانات والأرشيف.

---

## ✨ المميزات الرئيسية (Core Features)

1. **دليل شامل يضم أكثر من 520 تحليل طبي متخصص (+520 Clinical Tests)**
   - تغطية 18 قسماً طبياً: أمراض الدم (CBC)، وظائف الكبد، وظائف الكلى، الدهون والكوليسترول، السكري والتراكمي، الغدة الدرقية والأيض، الهرمونات والخصوبة، الفيتامينات والمعادن، سيولة وتجلط الدم، المناعة والروماتيزم، دلالات الأورام، الفيروسات والأمصال، المزارع والبكتيريا، الحساسية، البيولوجيا الجزيئية (PCR)، ومستوى الأدوية بالدم.
   - يشتمل كل فحص على: الكود، الاسم بالعربية والإنجليزية، السعر المعتمد، نوع العينة المطلوبة، شروط الصيام والتحضير، وقت ظهور النتيجة، والوصف التشخيصي.

2. **باقات فحص شامل متنوعة (18 باقة متكاملة)**
   - تشمل باقة الفحص الشامل VIP، وظائف الكبد والفيروسات، الكلى والنقرس، صحة القلب، السكري السنوي، الغدة الدرقية، تساقط الشعر والإرهاق، صحة الرجل والبروستاتا (+40)، صحة المرأة وتكيس المبايض، الرياضيين وبناء الأجسام، فحص ما قبل الزواج، متابعة الحمل، المناعة والمفاصل، جرثومة المعدة، صحة العظام، صحة الأطفال، دلالات الأورام المبكرة، والحمى والعدوى الحادة.
   - إمكانية التحكم بالمكونات المتغيرة (إضافة أو استبعاد الفحوصات الاختيارية) وحساب الخصم تلقائياً.

3. **إدارة العروض والخصومات اليومية (Daily Offers & Flash Discounts)**
   - إضافة وتعديل عروض اليوم الترويجية (نسب مئوية، أسعار خاصة للباقات، خصومات سريعة).
   - زر تطبيق فوري بضغطة واحدة يطبق الخصم على فاتورة المريض مباشرة.

4. **تعديل أي بند داخل البرنامج في كل الحقول (In-Place Edit Everywhere)**
   - زر تعديل (`Edit`) متوفر في كل صفحة وبطاقة وجدول:
     - تعديل بيانات أي تحليل (الاسم، السعر، الكود، العينة، الصيام، المدة، القسم).
     - تعديل الباقات والعروض ومحتوياتها.
     - تعديل إعدادات المعمل والفروع والخط الساخن.

5. **نمط العرض المصغر السريع (Compact Mode)**
   - زر التبديل بين النمط العادي والمصغر بضغطة واحدة لتسريع العمل في مكاتب الاستقبال وشاشات اللابتوب والتابلت.

6. **إرسال الفاتورة عبر الواتساب بنقرة واحدة (WhatsApp Integration)**
   - رسالة واتساب رسمية منسقة ببيانات المريض، الفحوصات المختارة، شروط الصيام والتحضير بدقة، والخصم المطبق، مع كود تأكيد الحجز.

7. **طباعة عرض السعر والفاتورة (Print & Thermal Receipts)**
   - دعم الطباعة بقياس A4 للمرضى والجهات، ودعم الفواتير الحرارية Thermal POS.

8. **تطبيق ويب تقدمي (PWA) وأوفلاين 100%**
   - تثبيت كتطبيق على Android و iOS و Windows و macOS.
   - استمرار العمل الكامل دون الحاجة لاتصال بالإنترنت مع مؤشر ذكي لحالة الشبكة.

## 🚀 التثبيت والتشغيل المحلي (Getting Started)

```bash
# استنساخ المستودع
git clone https://github.com/ramimokhtar228-maker/RT-LAB-PRICE.git

# الدخول للمجلد
cd RT-LAB-PRICE

# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

التطبيق سيعمل مباشرة على المتصفح عبر الرابط:
`http://localhost:3000`
